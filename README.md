# ESU Organizational Behavior student guide

A responsive, independent preparation guide for undergraduates exploring East Stroudsburg University's M.S. in Management and Leadership, Organizational Behavior concentration.

## View
Open index.html in a browser. No installation or build is needed. Upload index.html, styles.css, script.js, and .nojekyll to the repository root.

## GitHub Pages
In the repository, open Settings > Pages. Select Deploy from a branch, choose main and / (root), then Save. GitHub supplies the website address when deployment completes.

## Content boundaries
Accelerated eligibility for this concentration is not verified. Students are directed to the coordinator. General university thresholds are not presented as program approval. No deadlines, fees, completion duration, or shared credits are invented. The supplied example form is used only for sample coursework and its candidacy explanation; no personal student data or original PDF is published. Example entries total 33 credits; the form's stated degree range is 33-37 credits. Confirm the current catalog and individual approved plan with ESU.
